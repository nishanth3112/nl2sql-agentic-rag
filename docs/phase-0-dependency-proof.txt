Method
  before  python:3.11-slim, `pip install -r requirements.txt` (the old Dockerfile line)
  after   python:3.11-slim, `uv sync --frozen --no-install-project` from uv.lock
  Both resolved at the same moment (uv lock --exclude-newer 2026-10-21T23:03:16Z, the
  time of the "before" build), so newer releases cannot explain a difference.
  Installed distributions were listed with importlib.metadata inside each image.
  The committed uv.lock was then re-locked without --exclude-newer, so a plain `uv run`
  does not rewrite it. Only the [options] block changed; every package name and version
  was diffed before and after and is identical.

  nothing capped it; uv prefers stable releases and would have chosen 1.12.6. The beta is
  pinned in pyproject.toml so the resolved set stays the same. Moving to a stable
  dbt-core is a separate change.
